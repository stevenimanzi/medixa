# Medixa

Multi-branch Pharmacy Management Platform.

## Architecture

- **Backend**: Laravel API (`apps/api`)
- **Web Frontend**: React + TypeScript + Vite (`apps/web`)
- **Desktop**: Electron Shell (`apps/desktop`)
- **Database**: PostgreSQL
- **Cache/Queue**: Redis
